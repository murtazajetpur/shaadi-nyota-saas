## Creative objective

Make couples feel that a wedding invite should not be treated like a basic file attachment. Position Shaadi Nyota as a more memorable, mobile-first wedding website experience that keeps the couple's story, functions, venue, timings, and details in one easy link.

## Guardrails

- Do not mention plans or prices.
- Do not use the word "attendance."
- Do not imply RSVP is included in every website plan.
- Do not invent customer counts, testimonials, analytics, or instant publishing.
- Use natural Hinglish for an Indian audience.
- Use real product visuals only if product UI is shown.

## Recommended visual direction

Premium editorial carousel, 7 slides, 1080 x 1350 or 1080 x 1080.

Visual world:

- Deep maroon, ivory, muted gold, soft beige.
- Clean serif headlines with simple sans-serif support text.
- Wedding-paper texture, subtle gold linework, small ornamental dividers.
- Use real Shaadi Nyota website stills only as small proof moments, not AI-redrawn UI.
- Avoid fake phone UI and fake dashboard graphics.

Layout idea:

- Left side: old behavior / PDF frustration.
- Right side: Shaadi Nyota website experience.
- Use calm contrast, not aggressive "PDF is bad" energy.
