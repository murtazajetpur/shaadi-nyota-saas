# P02 - RSVP-First Script Options, Revision 5

Status: Awaiting user selection

## Creative direction

Main point: RSVP manage karna wedding planning ka hidden headache hai.

The Reel should start from a real Indian wedding problem: guests ask for venue, timing, event details, and RSVP one by one. Shaadi Nyota becomes the solution because the invite is beautiful, but also practical: guests can see all details and RSVP from one website link.

No Aanya. No plan language. Do not use the word "attendance." Do not imply WhatsApp footage unless supplied.

## Option 1 - Recommended: RSVP Headache

Bride: "Shaadi mein RSVP handle karna honestly sabse bada headache hota hai."

Groom: "Kisko details bheji, kisne confirm kiya, kaun baar-baar venue aur timing pooch raha hai..."

Bride: "Isliye humne Shaadi Nyota ka website invite banaya. Beautiful invite bhi, saare functions bhi, aur guests wahi se RSVP bhi kar sakte hain."

## Option 2 - More Natural Couple Talk

Groom: "Wedding invite bhejna easy hai. But RSVP manage karna?"

Bride: "That becomes a headache. Sabko details bhejo, replies track karo, phir follow-up karo."

Groom: "Shaadi Nyota mein invite website par hi functions, location, timing aur RSVP sab ek jagah handle ho jaata hai."

## Option 3 - Bride-Led, Slightly Emotional

Bride: "Main chahti thi invite beautiful ho, but sirf beautiful kaafi nahi tha."

Groom: "Guests ko details bhi clear chahiye, aur RSVP bhi simple hona chahiye."

Bride: "Shaadi Nyota par hamara invite website bana, jahan saare functions, details aur RSVP ek hi link mein mil gaye."

## Option 4 - Sharper Pain Point

Bride: "Shaadi ke time ek hi question baar-baar aata hai: details bhej do."

Groom: "Aur phir RSVP ka alag follow-up."

Bride: "Shaadi Nyota mein guests invite link open karte hain, details dekhte hain, aur wahi se RSVP kar dete hain. Simple."

## Option 5 - Most Practical

Groom: "Hum nahi chahte the ki RSVP ke liye hundred messages manage karne padein."

Bride: "Isliye Shaadi Nyota par invite website banaya."

Groom: "Guests ko functions, location, timing aur RSVP sab ek hi jagah mil jaata hai. Beautiful bhi, organized bhi."

## Option 6 - Premium But Still RSVP-Focused

Bride: "Invite sirf pretty card nahi hona chahiye."

Groom: "Wedding ke time details aur RSVP manage karna equally important hota hai."

Bride: "Shaadi Nyota mein invite beautiful website ki tarah open hota hai, aur guests saari details dekh kar wahi se RSVP kar sakte hain."

## Option 7 - Shortest Hook

Bride: "RSVP manage karna wedding ka real headache hai."

Groom: "Messages, details, follow-ups - sab alag-alag."

Bride: "Shaadi Nyota mein beautiful invite, wedding details aur RSVP sab ek website link mein aa jaata hai."

## My recommendation

Use Option 1 if we want the clearest pain-to-solution Reel.

Use Option 3 if we want it to still feel like a bride/couple decision, not only a problem statement.

Use Option 5 if we want the most practical, conversion-focused version.

After exact script approval, create fresh bride and groom character prompts and then plan the product proof around the RSVP screen being clearly visible.
