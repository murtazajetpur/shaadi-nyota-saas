# P02 - Script Options, Revision 4

Status: Awaiting user selection

## What changed from v3

The previous versions were too much like a neat feature list. These options use more Indian-wedding-native hooks: relatives asking questions, guests needing clarity, the invite feeling like the wedding has started, and the couple avoiding repeated manual explanations.

No Aanya. Character names can be decided after script approval.

## Option A - Recommended: Relatives Keep Asking

Bride: "Shaadi ke time sabse zyada messages kis baat ke aate hain?"

Groom: "Venue kahan hai, timing kya hai, RSVP kaise karna hai."

Bride: "Isliye humne Shaadi Nyota ka invite link bheja. Guests open karte hain, pura invite experience dekhte hain, aur details khud clear ho jaati hain."

## Option B - Best Couple Chemistry

Bride: "Main chahti thi invite beautiful lage."

Groom: "Aur main chahta tha guests ko details dhundhni na pade."

Bride: "Shaadi Nyota mein dono ho gaya. Ek link, beautiful opening, saare functions, location, timing aur RSVP."

## Option C - Guest POV Feel

Bride: "Hum chahte the guests link kholte hi bolein, 'yeh invite alag hai.'"

Groom: "Shaadi Nyota par invite ek website ki tarah open hota hai, jahan story, functions, details aur RSVP sab ek flow mein hota hai."

Bride: "Guest ke liye experience. Humare liye clarity."

## Option D - Less Salesy, More Real

Groom: "Honestly, wedding details manage karna messy ho sakta hai."

Bride: "Isliye humne PDF ya image forward karne ke bajay Shaadi Nyota ka website invite bheja."

Groom: "Guests ko opening se RSVP tak sab kuch ek hi link mein mil gaya."

## Option E - Premium First Impression

Bride: "Invite first impression hota hai."

Groom: "Toh humne socha, sirf card kyun bhejein?"

Bride: "Shaadi Nyota par guests link open karte hain, invite unfold hota hai, functions aur details dekhte hain, aur RSVP bhi wahi kar dete hain."

## Option F - Groom-Led Practical

Groom: "Mujhe bas ek cheez chahiye thi - guests ko baar-baar details na poochni padein."

Bride: "Aur mujhe chahiye tha invite beautiful feel kare."

Groom: "Shaadi Nyota ne dono simple kar diya: website invite, functions, details aur RSVP, sab ek link mein."

## Option G - Bride-Led Emotional

Bride: "Mere liye invite sirf information nahi tha."

Groom: "It had to feel like our wedding starts from that first link."

Bride: "Shaadi Nyota mein guests opening dekhte hain, story aur functions explore karte hain, aur RSVP bhi wahi kar sakte hain."

## Option H - Short, Punchy

Bride: "No PDF. No scattered details."

Groom: "Bas Shaadi Nyota ka invite link."

Bride: "Guests open karte hain, experience dekhte hain, functions samajhte hain, aur RSVP kar dete hain."

## My recommendation

Start with Option A if we want this Reel to feel useful and relatable.

Use Option B if we want stronger couple chemistry.

Use Option E if we want a more premium wedding-brand feel.

After script approval, decide character names and match the product recording or create a new matching screen recording.
