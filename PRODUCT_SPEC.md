# Shaadi Nyota V1 Product Spec

## Product
Shaadi Nyota is a fixed-theme wedding invitation website SaaS for Indian couples.

## Core Principle
Users select a fixed premium theme and only edit content/data. They cannot edit layout or design in V1.

## Guest Website Flow
1. Open to Reveal
2. Couple Section
3. Dynamic Event Sections
4. RSVP Section, only for RSVP packages
5. Thank You Section

## V1 Themes
1. Envelope Opening
2. Palace Door Opening
3. Scroll Opening

## Theme Rule
All themes must use the same backend data structure. Only presentation changes.

## V1 Package Types
1. Basic Website
   - Shows reveal, couple section, all events, thank you
   - No RSVP
   - No guest-wise event visibility
   - No WhatsApp automation

2. Website + RSVP
   - Personalized guest links
   - Guest-wise event visibility
   - Event-wise RSVP
   - Meal preference
   - RSVP dashboard

3. Website + RSVP + WhatsApp
   - Everything in RSVP package
   - Automated WhatsApp invite/reminders later

## Payment
Manual payment. Admin marks wedding as paid. Website can publish only after payment.

## MVP Goal
Use for founder's own wedding, test with friends/family, and sell to first 3 clients.
